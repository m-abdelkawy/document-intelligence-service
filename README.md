# Document Intelligence Service

Production-oriented backend system for document ingestion, processing,
search, and AI-powered knowledge retrieval.

## Status

🚧 Under active development

## Architecture

The system will evolve through several stages:

Java / Spring Boot
→ PostgreSQL
→ Redis
→ Kafka
→ Python AI Service
→ Vector Search / RAG
→ Cloud Deployment
→ Observability

## Goals

- Modern Java backend engineering
- Distributed systems
- Event-driven architecture
- Cloud-native deployment
- Python AI services
- Production observability
- Performance engineering

## Development

### Requirements

- Java 25
- Maven
- Docker
- PostgreSQL
